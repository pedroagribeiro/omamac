# omamac

A macOS theming tool that restyles Ghostty, Neovim, btop, bat, the system appearance and the wallpaper from a single theme definition, plus a Hammerspoon-hosted menu.

## Usage

```bash
omamac <command> [args]
  theme [name|--list|--current]
  font [name|--list|--current]
  bg [file|--next|--list|--current]
  menu-data
  preview <wallpaper>
```

## Development

Run tests with:
```bash
./tests/run
```
